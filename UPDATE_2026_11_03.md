# Доработка событий и просмотра видео — 03.11.2026

Исторический срез первого обновления интерфейса. Поздним поручением того же дня добавлен и проверен настоящий ручной онлайн одной C300; актуальный результат и файлы — LIVE_PLAN_2026_11_03.md и README.md. Ниже сохранены результаты до подключения live.

Поручение владельца: вернуть раздельные въезды/выезды, показывать связанный заезд автомобиля, события группировать по метрикам; из станции открывать онлайн и искать архив по дню/времени. Дополнение: названия Xiaomi-камер можно сопоставлять адресам (например, «Оптиков»), сохраняя связь по стабильному ID камеры.

## План до изменения кода

1. Backend-worker — только backend/demo.mjs, app.mjs, новые playback helpers и backend tests. Въезды и выезды отдельные события, один visitId на пару только в демонстрационных данных. Новый архивный API с RBAC и пересечением запрошенного интервала с реально доступной записью.
2. Frontend-worker — только frontend. Группы «Первое появление», «Открытие», «Автомобили», «Закрытие»; автомобильный блок показывает въезд, выезд и время в боксе на одной строке. Из станции/камеры доступны вкладки «Онлайн» и «Архив», выбор камеры и интервала, переход к записи от события.
3. Inventory-worker — только backend/camera-matching.mjs и tests/camera-matching.test.mjs: консервативное сопоставление по названию/адресу. Числа не игнорируются; неоднозначные и неподписанные камеры остаются непривязанными.
4. Root — контракт, безопасный импорт метаданных при доступном локальном go2rtc, интеграция и браузерная проверка. Независимый reviewer проверяет scope, время, пары и отсутствие выдачи записи за прямой эфир.

## Ограничения

- Нельзя придумать выезд или идентичность автомобиля по факту въезда. Демопары явно source=demo; реальный трекинг пока не подключён. Непарные наблюдения не дополняются выдуманными событиями.
- В существующем пилоте нет работающего постоянного live/полного облачного архива. Онлайн-вкладка должна честно показать статус подключения. Старый MP4 не выдавать за live и не привязывать к Сириусу.
- Реально доступный архив — пробный C300 MP4, 30.10.2026, 10,35 с, без подтверждённого адреса. Время надписи первого кадра 12:21:28; часовой пояс не подтверждён. Его можно искать/проигрывать в карточке проверки C300. Другие архивы — «не подключён», а не утверждение, что запись на камере отсутствует.
- Метаданные Xiaomi при импорте содержат только безопасный ID, имя и модель. DID/ключи/сессия/пароль/URL подключения не попадают в публичный bundle/API/log. Только чтение, камера не переименовывается.
- Не переносить камеры между аккаунтами и не изменять исходные таблицы или аудио-MVP.

## Приёмка

- В demo каждый vehicle_entry/vehicle_exit имеет согласованный visitId, exit позже entry; количество/агрегаты доступны только в рамках выданных камер.
- StationDetail не выводит десятки одинаковых строк общей лентой: метрики — отдельные блоки, заезды — пары с раскрытием/пагинацией.
- В station/camera видны «Онлайн»/«Архив»; архив проверяет дату и времена, ищет пересечение, проигрывает найденный диапазон либо честно сообщает статус.
- Архив/медиа требуют те же права, что камера; чужие записи и существование неизвестных ресурсов не раскрываются.
- Стабильный ID используется независимо от переименования; неоднозначный матч не применяется молча.
- Тесты старых RBAC, новые пары/архив/сопоставление, сборка и проверка desktop/mobile.

## Проверенный результат

- Интерфейс и API обновлены; отдельные въезды/выезды, четыре группы событий, парные заезды с длительностью и страницами по 8 строк. Непарные наблюдения всегда требуют проверки.
- Внутри одной карточки доступны «События и показатели», «Онлайн», «Архив»; выбор камеры сохраняется между вкладками. Событие заполняет архивную дату и время.
- Реальный пробный C300-клип ищется и проигрывается по пересечению интервала. В браузере участок 12:21:30–12:21:33 стартовал со смещения 2 с и остановился на 5 с. Неверный диапазон и отсутствие доступного фрагмента проверены отдельно.
- Снимок 17 камер импортирован без исходных идентификаторов/секретов; 12 совпадений, 5 без привязки. «Оптиков» сопоставлен с ул. Оптиков, 1к3; «Славянка», «Попова 226» без А и три общих названия не угаданы.
- Постоянный ID камеры сохраняется, но привязка к ПТО сейчас пересчитывается по имени при загрузке снимка. Переименование и обновление снимка могут изменить привязку; автоматического обновления или сохранения подтверждённых привязок нет.
- Независимый reviewer нашёл и проверил исправление двух ошибок: непарные события без отметки проверки и дата вымышленной записи у неподключённой камеры. Открытых замечаний по проверенной зоне не осталось; 65/65 автоматических тестов прошли.
- Root проверил браузером desktop 1176×884/mobile 390×844, группы/пагинацию/вкладки, фильтр выездов, переключение двух камер Бийска, статусы импортированных камер и архив. В консоли нет ошибок/предупреждений; ширина страницы и диалога на mobile не превышает viewport. Скриншоты сохранены отдельно от кода.
- Сборка Vite успешна: index-DZQKk2ue.js, index-DjpMO7JO.css. Прямой эфир, полный архив и настоящий ИИ остаются неподключёнными; исходная таблица и аудио-MVP не изменялись.
