# Поставка кабинета камер для проверки программистом

Подготовлен отдельный Git-проект только камеры/кабинет. Родительский аудиопроект, сервер компании, реальные пользователи и приватные подключения камер не изменялись. Автоматического развёртывания нет.

## Состав

- Backend Node 24 и React-интерфейс с текущей согласованной структурой.
- Lockfile и точный pnpm 10.28.2, Dockerfile, Compose, `.env.example` и CI без SSH/deploy.
- Серверный режим: отдельный bootstrap-администратор из файла секрета, отказ от учебной БД, Secure cookies, проверка Host/Origin, ограничение попыток входа и сохранённые границы ролей.
- Контейнер без root, с read-only файловой системой, собственным томом и лимитами. Хостовый порт только `127.0.0.1`; чужие каталоги и Docker socket не подключаются.
- Инструменты резервирования/восстановления, автоматическая проверка состава Git и инструкции для программиста.
- Собственный диагностический Java/Python-код и MIT-helper сохранены в исходниках. В default-образ они не входят. Сторонние transport-бинарники, токены, записи и приватные локальные настройки не распространяются.

Регрессионный тест, независимый review и браузерный цикл «вход → выход → повторный вход» прошли без перезагрузки страницы.

Чистая сборка выполнена на Windows с Node 24.22.1 и hoisted layout pnpm. Она подтверждает существование и сборку зафиксированных frontend-зависимостей, но не заменяет Linux/Docker-проверку. В CI указан Node 24.22.2 и стандартная установка pnpm; Docker на исходном ПК отсутствует. Код опубликован в закрытом [dmecosmotr-ops/ekosmotr-video](https://github.com/dmecosmotr-ops/ekosmotr-video). Фактического deploy на сервер компании не было.

## Что проверяет программист

Начать с [инструкции развёртывания](docs/SERVER_DEPLOYMENT.md). Согласовать домен, свободный локальный порт, секрет администратора, собственный том, лимиты и резервирование; пройти CI и контейнерный smoke. Затем настроить существующий HTTPS reverse proxy и проверить реальные ограниченные роли. Эта поставка не запускает ИИ или все камеры в фоне.

Подключение настоящих камер — отдельный пункт [обзора видео](docs/VIDEO_DEPLOYMENT_REVIEW.md). Реестр приватных камер и экспериментальный клип автоматически не переносились. Для существующего диагностического транспорта остаются вопросы лицензии и проверки отправителей. Постоянная запись, полный архив, GPU-анализ и нагрузка 70 ПТО этой поставкой не подтверждены.

## Секреты и источник

Репозиторий предназначен для закрытого размещения, поскольку содержит внутренний справочник станций. Перед коммитом проверяется именно индекс Git: разрешённые пути исходников, отсутствие приватных/бинарных файлов и наиболее явных форматов ключей. Такая проверка и review не являются гарантией безопасности всей инфраструктуры.

История интерфейса и предыдущих локальных проверок сохранена в датированных отчётах. Их абсолютные локальные ссылки служат доказательствами исходного стенда, не зависимостями Linux-runtime. При первой публикации удалённое дерево коммита 8e9dba0cc411c8004fce9e6ad6d8f699cf80c64f — dfdf12363324c926c4c41ce7f411662db66f8450 — совпало с локальным проверенным деревом из 97 файлов. После последующего исправления выхода нужно смотреть результат CI именно последнего коммита в разделе Actions. Настоящая установка компании, HTTPS с её доменом, реальное видео на Linux и ИИ остаются непроверенными.
