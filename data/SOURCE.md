# Источник списка станций для пилота

Экспорт выполнен 03.11.2026 из существующего внутреннего реестра, по поручению использовать имеющиеся адреса и распределение станций. Источник прочитан только для чтения и не изменялся. Google-таблицы не открывались и не менялись.

Файл-источник: `analysis/camera_inventory_2026_10_22/private/outputs/camera_inventory_unified_2026_10_23/Единая_ревизия_камер_2026-10-23.xlsx`.

Это локальный шаблон ревизии от 23.10.2026, подготовленный по коммерческому отчёту за 11–17.10.2026. Он подтверждает список и назначения на дату подготовки, но не актуальность перечня на сегодняшний день и не результат продолжающейся ревизии камер.

## Данные

`stations.json` — UTF-8 JSON-массив из 71 объекта, 21 значения географического региона и 9 руководителей.

| Поле | Правило |
|---|---|
| `id` | `pto_` + полный SHA256 от адреса после Unicode NFKC, `casefold`, свёртки пробелов и удаления пробелов по краям |
| `region` | Дословно колонка B регионального листа; это географическая группировка исходника |
| `city` | Первый компонент полного адреса до первой запятой; производное поле для навигации, не отдельный проверенный муниципальный справочник |
| `address` | Дословно колонка C регионального листа, включая город/населённый пункт |
| `manager` | Название регионального листа, дословно |
| `sourcefilename` | Имя исходного XLSX без абсолютного пути |

Обработаны девять региональных листов, только строки с числовым порядковым номером в A, непустыми B/C. Лист «Итоговая» с формулами не используется для экспорта. Порядковые номера в A не являются постоянными ID. Произведена проверка числа записей, уникальности адресов и ID, точного совпадения тройки руководитель/регион/адрес с исходными строками и повторного чтения сохранённого JSON.

ID сохраняется при перестановке строк, смене руководителя или региона. При изменении самого адреса его хеш изменится; исправления адресов в дальнейшем должны сопровождаться явной миграцией привязок, а не молчаливым повторным импортом.

## Границы использования

- Экспортированы только шесть перечисленных полей. Финансовые показатели, IP, DID, ключи, пароли, токены, видео, телефоны и электронные адреса не переносились.
- Фактическое наличие, число, модели и исправность камер в этот JSON не включены. Он не доказывает наличие камеры на каждой станции.
- Полученные ранее шесть камер Xiaomi автоматически к этим адресам не привязаны. Совпадение имени камеры с частью адреса не считается подтверждённой привязкой.
- `manager` описывает ответственность в исходном реестре. Это не созданный пользователь сервиса и не автоматическая выдача прав. Учётные записи и права назначаются отдельно.
- Экспорт предназначен для внутреннего пилота; он не является публикацией полного реестра в открытом Интернете.
