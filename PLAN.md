# Camera pilot implementation plan — 03.11.2026

**Goal:** работающий локальный пилот веб-сервиса Экосмотр с входом, ролями, доступом по станциям/камерам, базовыми видеометриками и журналом действий.
**Architecture:** отдельное приложение вне аудио-MVP. Backend Node 24 HTTP + SQLite/crypto из стандартной библиотеки; frontend React/Vite. Только loopback. Текущий shared Xiaomi-доступ сохраняется; перепривязка и новый сбор видео не выполняются.
**Execution:** главный агент — UI/интеграция/браузерная проверка; backend-worker — API/RBAC/tests; inventory-worker — read-only XLSX → станционный реестр; независимый reviewer — безопасность, статусы и границы данных. Пользователь поручил собрать пилот; этот конкретный план предшествует коду.

## Scope

- Реальный вход/выход с хешами паролей и серверными сессиями; роли admin/director/regional. Перезапуск сохраняет пользователей и выдачи прав.
- Admin видит всю сеть и создаёт любые роли; director создаёт/редактирует только regional в рамках своих прав. Regional — только просмотр разрешённых ресурсов.
- Полная станция даёт все её камеры; отдельная камера — только эту камеру и минимальные сведения её станции. Директор не может выдавать больше собственных прав. Проверка на backend, не только скрытие кнопок.
- Реестр из существующего XLSX: 71 станция, 21 регион, 9 руководителей. Новые станции и назначения не выдумывать.
- Базовые показатели: открытие, закрытие, первое появление человека/предполагаемого сотрудника, раздельные въезды и выезды. По новому поручению 03.11.2026 добавлены связанные демозаезды с общим visitId. Въезды не равны уникальным клиентам; первое появление не доказывает личность/начало рабочего дня. Группы событий и видео/архив описаны в UPDATE_2026_11_03.md.
- Демо события/метрики явно обозначены как демо. Для остальных дней и станций — нет данных. Никаких фиктивных AI confidence, онлайн-камер или подключений.
- Имеющийся клип C300 30.10 можно показать в отдельной проверке подключения без привязки к адресу: это клиентская зона, а не ворота/линия. Только через авторизованный API; не копировать в public.
- Модели ИИ и постоянный приём ещё не реализованы: этот пилот демонстрирует интерфейс и контракт результатов анализа. Отсутствие данных не трактуется как закрытие или отсутствие эксперта.

## Risks / limitations

Локальный пилот, не публичная production-система. Пароли начальных тестовых аккаунтов только для этого стенда, не Xiaomi; не использовать реальные пароли. Нет корпоративной многокомпанейной модели без определения юридических компаний; директор ограничен выданным набором станций/камер. По снимку названий сопоставлены 12 из 17 реальных камер; ракурс и адрес требуют проверки. Привязка пересчитывается при запуске, подтверждённая постоянная привязка пока не сохраняется. Настоящие AI-метрики нужно подключить отдельным этапом и проверить по видео.
