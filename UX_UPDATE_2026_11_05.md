# Обновление кабинета камер — 05.11.2026

Внедрён согласованный `UX_AUDIT_2026_11_03.md` в существующем локальном пилоте: http://127.0.0.1:3210/. Новые зависимости не устанавливались. Рабочие пользователи и назначения не изменялись; форма доступа проверена как черновик с отменой. Исходные таблицы, Xiaomi-аккаунт, сеть ПТО и аудио-MVP не изменялись.

## Что изменилось для пользователя

1. **Адрес первым.** Камеры сгруппированы по ПТО, заголовок — город и адрес. Ниже название камеры, ракурс, модель и доступность видео. Большие пустые изображения удалены; добавлен поиск по адресу, городу, руководителю и имени камеры. Кнопки «Онлайн / Архив» доступны по фактической настройке сервиса.
2. **Рабочие данные отдельно от примера.** Первый вход показывает рабочий режим и текущий день браузера. В нём 18 позиций: 17 импортированных камер и отдельная пробная запись; 6 позиций без адреса, просмотр настроен у одной. Эти числа относятся к текущему локальному снимку, не к полной ревизии сети. «Пример данных» включает пять учебных камер и события 30.10.2026, без подмешивания в рабочие показатели. Адреса всех разрешённых ПТО остаются находимыми.
3. **События по показателям.** Четыре раскрываемых блока: «Первое появление и открытие», «Автомобили», «Закрытие», «Требует проверки». Внутри — адреса и время/числа, затем подробности. ПТО с отметками идут первыми. Есть поиск, отдельные фильтры руководителя и географического региона, хронология и страницы. Раскрытый блок сохраняется при поиске; номер страницы сбрасывается. Въезд и выезд остаются разными наблюдениями, у каждого своё действие записи. Неизвестный результат не заменяется нулём.
4. **ПТО → нужное содержимое.** Адрес и вкладки «Сводка дня / Онлайн / Архив» стоят сверху. На онлайн сразу выбор камеры и плеер, без старой даты и исторических метрик. Выбирается камера с настроенным просмотром; запуск ручной. Явный выбор пользователя сохраняется между вкладками.
5. **Честная доступность.** Отсутствующий архив не предлагает активный поиск. Событие без записи сообщает «Запись пока недоступна»; доступный момент можно открыть отдельно. `archiveAvailable` в API проверяет существование пробного файла, а `liveAvailable` по-прежнему означает настройку просмотра, не текущую исправность камеры. Пробный архив — отдельный клип, полный архив Xiaomi этим обновлением не подключён.
6. **Понятные доступы.** Описаны возможности ролей, дерево руководитель/регион → ПТО → камеры и адресный итог «Пользователь увидит». Камеры полного ПТО не считаются повторно. Директор с доступом к одной камере не может назначить ПТО целиком. Поиск не меняет выбранные права; скрытые количества камер не раскрываются. Региональный кабинет называется «Мои ПТО».
7. **Действия пользователей.** Фильтры по периоду, человеку и категории. Время и границы дней явно относятся к часовому поясу браузера. Указан предел последних 300 загруженных записей. Обновление своей сессии после сохранения пользователя сохраняет дату, режим и разрешённые фильтры; видео закрывается, доступные объекты перечитываются.
8. **Телефон и клавиатура.** На телефоне обзор использует компактные карточки. В модальном окне видео находится сразу под вкладками. Границы фокуса удерживают клавиатуру внутри окна, не мешая нативным видеоконтролам.

## Как проверить вручную

Открыть кабинет → «Камеры» → найти Бийск → онлайн второй камеры. Для структуры событий выбрать «Пример данных» → «События ПТО» → нужную метрику → адрес. Для архива вернуться к рабочим данным → «Камеры» → «Есть запись в сервисе» → пробная C300 → «Доступный фрагмент». Форму пользователей можно открыть, проверить адресный итог и закрыть через «Отмена».

## Границы результата

Это доработка интерфейса работающего пилота. Настоящий ИИ-анализ, подтверждённое покрытие суток, полный архив, корпоративный сервер/домен и устойчивость 24/7 не появились автоматически. Первый неудачный и следующий успешный запрос показывают, что стабильность удалённого источника ещё требует отдельной проверки. Сопоставление камеры с ПТО по названию требует подтверждения на месте. Лица и личность эксперта не определяются; въезд не равен уникальному клиенту. Публичная публикация не выполнялась.
